# Definition Matrix of System Performance Benchmarks

- **Correct Selection Rule:** Validated as identifying an intervention difference vector ($\hat{\delta} > 0$) when the true ground truth treatment effect vector is positive ($\delta_i = 0.50$).
- **Interval Coverage:** The definitive mathematical proportion of Monte Carlo replicates where the calculated 95% Confidence/Credible boundaries enclose the true target simulation parameters.
- **Monte Carlo Standard Error (MCSE):** Quantifies the local statistical simulation uncertainty driven strictly by the finite count of replicate evaluation runs ($B=1000$).
