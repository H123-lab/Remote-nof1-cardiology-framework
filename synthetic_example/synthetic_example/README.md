# Synthetic Single-Patient Trial Data Catalog

This directory houses the foundational synthetic example dataset and structural parameters representing a 6-period (ABABAB) remote N-of-1 trial under high-frequency longitudinal cardiovascular monitoring conditions.

## Directory Index
- `data_dictionary.csv`: Structural definition of relational columns and unit metrics.
- `simulation_parameters.yaml`: Pre-specified mathematical constants enforcing baseline, carryover, noise, and missingness boundaries.
- `synthetic_nof1_data.csv`: Automated row tracking profile output showing 84 distinct home blood pressure telemetry proxies.
